# MarketLens

竞品分析工具。上传产品资料或输入产品名称，自动检索公开来源，生成可横向比较、每条结论都能回溯到原文的报告。

## 功能

- **两种入口**：上传 Excel / CSV / PDF，或只输入一个产品名称
- **多来源检索**：品牌官网、行业媒体、专业评测、行业研报、电商页面
- **横向比较**：按维度并排展示各品牌数据，不需要横向滚动
- **证据可溯源**：每条事实都附原文链接，点开即可核对
- **多品类通用**：不依赖行业词表，换品类不需要改代码

## 安装

需要 Python 3.10 及以上。

```bash
pip install -r requirements.txt
```

## 使用

1. 按下一节配置 API Key
2. 启动应用：

```bash
streamlit run app.py
```

3. 浏览器打开 `http://localhost:8501`

未配置 Key 也能启动，此时进入本地演示模式（仅使用上传资料，不联网检索）。

## 配置

复制 `.streamlit/secrets.example.toml` 为 `.streamlit/secrets.toml`，填入 Key：

```toml
# 必填：用于识别产品、抽取事实
FILE_ANALYSIS_API_KEY = "你的百炼 API Key"

# 必填：用于联网检索
QWEN_SEARCH_API_KEY = "你的百炼 API Key"
```

以下为可选，用于补充来源：

```toml
TAVILY_API_KEY = ""
BOCHA_API_KEY = ""
EXA_API_KEY = ""
```

也可以用环境变量配置（变量名相同），适合部署到服务器。

> Key 只保存在本地。`.gitignore` 已排除 `secrets.toml`，不会误提交。

## 报告内容

| 区块 | 说明 |
|---|---|
| 一页结论 | 3–5 条对比性结论，说明谁在哪个维度领先 |
| 横向比较 | 按维度分组，同一指标下并列各品牌 |
| 证据明细 | 每条事实一行，附「打开」链接直达原文 |
| 来源清单 | 每个来源的读取状态，失败原因会标注 |

表格中的「—」表示该指标暂无有依据的数据，系统不会用推测填空。

## 支持的资料

| 格式 | 说明 |
|---|---|
| Excel / CSV | 按表头提取字段，列名即比较维度 |
| PDF | 文本型 PDF；扫描件暂不支持 |
| 产品名称 | 只输入名称时，系统先确认产品身份再检索竞品 |

## 已知限制

- 扫描件 PDF 未接 OCR，PDF 内嵌表格按正文处理
- 天猫、淘宝、拼多多、抖音的商品页没有公开索引，价格取自比价站与专业评测页，不绕过反爬
- 仪器类产品多按询价制，公开渠道无报价时该项留空
