# MarketLens

把散落在公开渠道的竞品信息，整理成**可横向比较、每条结论都能回溯到原文**的分析报告。

上传 Excel / CSV / PDF，或只输入一个产品名称即可。

---

## 解决什么问题

AI 竞品工具已经能"一键生成报告"，但有三个通病：

| 通病 | 表现 |
|---|---|
| **编造** | 大模型"回忆"出看起来合理的价格、参数 |
| **不可核对** | 给结论不给来源，或给一个打不开的链接 |
| **不可比较** | 各家信息维度不同，拼不成一张表 |

MarketLens 把"可溯源"做成硬约束：只有网页**原文**中明确写出的内容才算事实；无依据时表格留空而非推测；矛盾值全部保留。不绕过登录、付费墙、验证码或反爬。

---

## 多品类通用

品类识别、比较维度、品牌判断全部由模型按实际产品判定，代码中**不含任何行业关键词表**。实测六个差异极大的品类，全程零代码改动：

| 品类 | 入口 | 横向覆盖 |
|---|---|---|
| 保健品（蛋白粉） | 产品名 | 6/6 对象 |
| 实验室仪器（培养箱） | Excel | 资料内 4 品牌各满格 |
| 酶标仪（Tecan） | PDF | 分析对象 6/6 + 竞品 5/6 |
| SaaS（飞书） | 产品名 | 5/6 对象 |
| 服装（冲锋衣） | 产品名 | 5/5 对象 |
| 家电（扫地机器人） | 产品名 | 5/5 对象 |

## 快速开始

```bash
pip install -r requirements.txt
streamlit run app.py
```

无需 API Key 也能运行（本地演示模式）。配置参考 `.streamlit/secrets.example.toml`。

> 真实 Key 不要写入 `app.py`、README、数据库或任何会提交到仓库的文件。

## 迭代中的几个判断

完整记录见 [docs/迭代历程.md](docs/迭代历程.md)。

**链接 404 不是校验不严，是接口选错。** 兼容接口不返回检索来源，模型只能凭记忆编 URL。改用原生接口，只采信接口返回的来源。

**竞品没数据不是检索能力不够。** 统计调用记录发现 16 次搜索有 6 次纯重复——三个引擎收到了同一批查询。重新分配预算后，有数据的竞品从 1/6 升到 6/6。

**通用性不靠堆规则。** 开发中曾堆过三张关键词表，都在用关键词模拟语义判断。删掉后改为"模型做语义、代码做机制"。

**PDF 内容丢失源于整体截断。** `[:26000]` 让 28 页手册只传了前 6 页。改为按页分配预算。

## 能力边界

- PDF 支持文本型文件；扫描件未接 OCR，内嵌表格按正文处理
- 天猫、淘宝、拼多多、抖音无公开索引且价格有字体加密，这几家的价格取自比价站与评测页，**不绕过反爬**
- 仪器类产品多按询价制，无公开报价时留空
- 只上传竞品清单、未指明自家产品时，报告以品类为标题
